## 方式五：API 调用（开发者）

如果你是开发者，想在代码中调用，可以用 API。

### 优点

✅ 灵活性高

### 缺点

❌ 需要编程知识  
❌ 需要付费（按使用量）  
❌ 配置相对复杂

### 怎么用

**第一步：获取 API Key**

有两种方式：

**方式 A：官方 API**
- 访问 Google AI Studio
- 创建 API Key
- 需要魔法上网和外币卡

**方式 B：第三方 API（推荐）**
- 使用国内的 API 中转服务
- 价格更便宜
- 不需要魔法上网
- 推荐中转站：https://apipro.maynor1024.live/

**第二步：配置代码**

以 Python 为例：

```python
import google.generativeai as genai

# 配置 API Key
genai.configure(api_key='your-api-key')

# 创建模型（支持调用 Gemini 3.6 Flash）
model = genai.GenerativeModel('gemini-3.6-flash')

# 生成内容
response = model.generate_content('Hello!')
print(response.text)
```

**第三步：调用 API**

在代码中调用，就像调用函数一样简单。

### 适合谁

- 开发者：需要集成到应用
- 企业：需要批量处理
- 高级用户：需要自动化
